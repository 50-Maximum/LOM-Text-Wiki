# LOM-Text-Wiki

这是一个公开发布的文本查询型游戏资料仓库，主要用于分发与离线检索使用。

## 项目定位

- 本仓库面向用户下载与使用
- 目标是提供可查询的游戏文本资料与整理后的条目数据
- 本仓库不作为协作开发项目运行
- 允许查看和下载，但不接受外部内容提交

## 下载方式

建议使用 GitHub Releases 下载正式发布版本。

正式发布包中通常包括：

- 可执行文件
- 游戏文本数据
- 查询工具或脚本
- 说明文档

请在仓库主页的 Releases 页面查看并下载最新版本。

## 协作规则

本仓库为只读型发布仓库。当前不接受以下内容：

- Pull Request
- 提交补丁
- 文本修正
- 新增条目
- 内容贡献
- 任何形式的直接仓库改动提交

如需沟通、反馈或咨询，请通过作者公开渠道联系，不要直接向仓库提交内容。
