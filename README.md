# 活侠传追踪Wiki

把《活侠传》的简体中文文本全部提取、结构化，做成一个能全文检索、条目互链的本地百科。

单机运行，独立窗口，不改动游戏文件；除「检查更新」外不联网。

## 这是个什么东西

游戏剧情量大，台词散落在 Unity 资源包的 Story 表与章节脚本里。想回头查一句话、一个选择、一个旗标出现在哪场戏，几乎不可能。

这个工具把全部文本落进可检索的库，并把「这句话属于哪一场、这一场在哪个阶段、这个选项通向哪里、这个条件依赖哪些旗标」串起来，查得到原文，也看得到前后关系。

## 使用前请注意

- 除原文台词外，事件标题、剧情段划分、人物分节等都属于整理工作。游戏本身没给这些内容命名，标题由整理者拟定，**置信度不如原文**。
- 考据角色、地点、势力时，请优先看剧情事件与事件编号序列，并以原剧情文本为最终依据。
- 本工具不是攻略。它展示的是文本与条件，不保证哪条路走得通、哪条路收益高。
- 建议先自己通关一遍再使用，剧透范围是全部。

## 功能

- **全文检索**：FTS5 索引，命中到句，点开就是整场戏
- **阶段目录**：外姓弟子、南宫寿宴、江陵围城、唐门衰败、比武招亲、武林大会、武林盟进攻唐门、不限时间
- **场景页**：台词按序排列，标出旁白与心声；分支选项、旗标改动就地显示，选项可点直达下一场
- **事件页**：说明谁在哪做什么、为什么、结果如何，并给出所属阶段与场景
- **剧情段 / 剧情单元**：连续场景合段，同族段并成单元，写清起因、转折、结果；互斥走向分列，一次只走一条
- **人物页**：身份、称号、所属势力、相关事件分节；同名不同人分开建页
- **势力页**：上级、下辖、本派成员三块，带数量
- **地点页**：可达 / 仅提及 / 剧情场景地三态，上下级成树；同名不同处的地点分页并互相注明
- **数值与旗标页**：以游戏自带名称表为准；旗标除编号外附一句人话，说明在哪场戏被置成什么值
- **触发链查询**：输入事件、判定或旗标，列出上游条件、涉及场景与写入点，回答「要发生这件事得先做什么」
- **攻略对照**：71 条攻略事件与年表按年月旬对齐场景
- **地图**：底图加 433 个事件节点
- **自动更新**：检测到新版会提示，下载后校验 SHA256 再替换

## 运行

双击 `活侠传追踪Wiki.exe` 即可。

程序在 `127.0.0.1:8765` 起本地服务并开独立窗口，关窗即退出，不留后台进程。不需要安装，不需要 Python，不联网也能用。

若独立窗口打不开，会退化为系统 Edge 应用窗口或默认浏览器，效果相同。

## 数据来源与声明

游戏文本与立绘出自《活侠传》（Legend of Mortal），版权归开发组所有。

本项目只把已有文本整理成便于检索的形式，供玩家查阅，不用于商业用途；不包含游戏可执行文件，不涉及破解与修改。

条目页中的标题、分段、归属判断均落在原文台词上，页面保留出处，可自行核对。
